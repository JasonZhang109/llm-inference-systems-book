## 重绘与使用规则

- 只有原表给出精确数值的才画精确值；区间型结论画区间，不取中点冒充点估计。
- 同一张图内若单位不同（如 $/GPU-hour 与 TWh），必须分面板，不共用一条纵轴。
- 第三方测算（Epoch 成本模型、LBNL 情景）与第三方实测（MLPerf、微基准、trace）必须分标证据类别，不混为一谈。
- API 标价（list price）不是厂商成本，也不是自建单次推理成本；标价下降幅度不得直接写入成本模型。
- 跨平台排名前必须条件等价：加速器数量、可用性分类（Available/Preview）、模型、场景、约束档位须一致。
- 真实 trace 的峰值/均值比必须带统计窗口；长度分布必须区分输入与输出。
- 图形为本书重新绘制，不是原始工具截图。原始网页、论文、商标版权归原权利人。
